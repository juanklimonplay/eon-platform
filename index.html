01 · Problem & solution

In Latin America, business happens on WhatsApp.

Clubs, hotels and tradespeople get their customers through chat — but the person answering is usually the owner, between everything else.

The problem

  • Messages pile up after hours and on weekends; replies come late or never.
  • Payments arrive as transfer screenshots that someone has to check by hand.
  • Member lists and records live in notebooks or scattered spreadsheets.
  • Enterprise tools are priced, designed and written for other markets.

The solution

  • An AI assistant on the business's own WhatsApp number, answering at any hour.
  • Payments via Mercado Pago or bank transfer, with the AI reading the receipt.
  • Records, roles and a CRM in a web panel that updates in real time.
  • Vertical products shaped for each kind of business, on one shared platform.

03 · How Eon uses Claude

Claude in the product, and Claude building it.

Two roles: Claude is the primary AI provider behind every bot, and Claude Code is how a single person ships a platform of this size.

In production

  1. Primary providerClaude handles the conversations, the business-specific prompt and reading payment receipts.
  2. Automatic fallbackIf a call fails, the platform switches to a backup provider so the customer still gets an answer.
  3. One prompt per businessEach tenant configures how its assistant speaks.

In development

  1. End to end with Claude CodeBackend, panel, bots and side projects are written with Claude Code.
  2. Security reviews & testsChanges go through security reviews and tests before merging.
  3. Cloud sessions → pull requestsWork runs in Claude Code cloud sessions and lands as reviewed PRs — including this page.
// simplified sketch of the idea, not the actual source
async function reply(tenant, chat) {
  try   { return await claude(tenant.prompt, chat) }   // primary
  catch { return await backup(tenant.prompt, chat) }   // automatic fallback
}
