01 · Problem & solution

In Latin America, business happens on WhatsApp.

Clubs, hotels and tradespeople get their customers through chat — but the person answering is usually the owner, between everything else.

The problem

  • Messages pile up after hours and on weekends; replies come late or never.
  • Payments arrive as transfer screenshots that someone has to check by hand.
  • Member lists and records live in notebooks or scattered spreadsheets.
  • Enterprise tools are priced, designed and written for other markets.

The solution

  • An AI assistant on the business's own WhatsApp number, answering at any hour.
  • Payments via Mercado Pago or bank transfer, with the AI reading the receipt.
  • Records, roles and a CRM in a web panel that updates in real time.
  • Vertical products shaped for each kind of business, on one shared platform.

C# · Win32 overlapped I/O · .NET GC

EonPS4Controller · a memory-corruption crash in DS4Windows 3.9.9una caída por corrupción de memoria en DS4Windows 3.9.9

Symptom: AccessViolationException (0xc0000005) inside coreclr.dll, in unrelated places — the kind of crash people blame on "drivers".

Isolating it: with the editor open 45 s and the controller connected, 4/8 runs crashed. Service stopped: 0/8. Garbage collector nearly idle: 0/8. It needed both live I/O and a GC pass — the signature of a movable buffer the OS is still writing to.

Root cause: overlapped reads were issued on a managed byte[] pinned only for the duration of the call. The GC could move it while the kernel was still going to write into the old address; and on a timed-out wait the read stayed pending without CancelIoEx. Same pattern on the output path.

Fix: keep the buffer pinned for the whole operation and cancel with CancelIoEx when the wait ends early. A stress script reproduces the crash on demand.

Síntoma: AccessViolationException (0xc0000005) dentro de coreclr.dll, en lugares sin relación — el tipo de caída que todos le echan a "los drivers".

Aislarlo: con el editor abierto 45 s y el joystick conectado, 4 de 8 corridas se caían. Con el servicio detenido: 0/8. Con el recolector de basura casi quieto: 0/8. Hacían falta las dos cosas: E/S viva y una pasada del GC — la firma de un búfer movible que el sistema todavía escribe.

Causa: lecturas superpuestas sobre un byte[] fijado solo durante la llamada. El GC podía moverlo mientras el kernel todavía iba a escribir en la dirección vieja; y si la espera vencía, la lectura quedaba pendiente sin CancelIoEx. Lo mismo en la salida.

Arreglo: mantener el búfer fijado durante toda la operación y cancelar con CancelIoEx si la espera termina antes. Un script de estrés reproduce la caída cuando se quiera.

Bluetooth HID · SBC · WASAPI over raw COM

PC audio in the PS4 controller's speaker — over Bluetooth, in-processEl audio de la PC en el parlante del joystick de PS4 — por Bluetooth, dentro del programa

DS4Windows never shipped Bluetooth audio. EonPS4Controller does it natively: a hand-written SBC codec (32 kHz encoder, 16 kHz mono decoder for the controller's mic), Bluetooth CRC-32 and raw 0x17 audio reports, a 16 ms engine loop, WASAPI loopback and per-process capture through hand-rolled COM interop — no NuGet packages, and per-app routing (the game to the controller, everything else stays on the PC).

Then it stuttered. With music-reactive lights on, audio choked. Measured, not guessed: a write-latency histogram showed slow writes (>8 ms) jumping from ~3 % to 33 %. A lock didn't help; an A/B on a volume flag didn't either. The real cause was Bluetooth sharing radio time with 2.4 GHz Wi-Fi, which makes the link fragile under load — reproduced on purpose to measure the curve.

Fix — adaptive rate limiting: every ~1.5 s the engine measures the slow-write fraction; above 15 % it steps the light/rumble budget down (unlimited → 12 → 6 → 3 reports/s), below 6 % for 4 windows it steps back up. Token bucket, burst 3, newest state wins. Light and rumble share the same 0x11 report, so one write carries both. On a healthy link it limits nothing.

DS4Windows nunca tuvo audio por Bluetooth. EonPS4Controller lo hace nativo: un códec SBC escrito a mano (codificador de 32 kHz, decodificador mono de 16 kHz para el micrófono del joystick), CRC-32 de Bluetooth y reportes de audio 0x17 crudos, un motor con bucle de 16 ms, captura WASAPI del sistema y de un solo proceso con interop COM propio, sin paquetes NuGet, y ruteo por aplicación (el juego al joystick, lo demás en la PC).

Después se trababa. Con las luces al ritmo de la música, el audio se cortaba. Se midió en vez de adivinar: un histograma de latencia mostró que las escrituras lentas (>8 ms) pasaban de ~3 % a 33 %. Un candado no ayudó; un A/B sobre un flag de volumen tampoco. La causa real: el Bluetooth comparte la radio con el Wi-Fi de 2,4 GHz, que vuelve frágil el enlace con carga — reproducido a propósito para medir la curva.

Arreglo — límite adaptativo: cada ~1,5 s el motor mide la fracción de escrituras lentas; arriba de 15 % baja el presupuesto de luz/vibración (sin límite → 12 → 6 → 3 reportes/s), debajo de 6 % durante 4 ventanas sube un paso. Cubo de fichas, ráfaga 3, gana el estado más nuevo. Luz y vibración comparten el reporte 0x11, así que una escritura lleva las dos. Con el enlace sano no limita nada.

Node · fetch · Anthropic Messages API

An AI layer that never leaves a customer on readUna capa de IA que nunca deja a un cliente en visto

One shared module with no SDK dependency, used by the hotel bot, Sedes, Sonriar and Multiservicios. It converts the bots' OpenAI-style messages into the Anthropic format (system prompts merged, base64 images turned into image blocks so Claude can read transfer receipts and ID photos), treats refusals and empty answers as failures, and gives Claude a deadline. If Claude fails or is late, the request falls through to a parallel race across several NVIDIA-hosted models — first good answer wins — and after 15 s the customer gets a safe reply instead of silence. Without an Anthropic key, every bot keeps working on the backup path exactly as before.

Un solo módulo compartido, sin depender de un SDK, que usan el bot del hotel, Sedes, Sonriar y Multiservicios. Convierte los mensajes estilo OpenAI de los bots al formato de Anthropic (prompts de sistema unidos, imágenes en base64 pasadas a bloques de imagen para que Claude lea comprobantes de transferencia y fotos de carnet), toma una negativa o una respuesta vacía como falla y le pone a Claude un plazo. Si Claude falla o tarda, el pedido pasa a una carrera en paralelo entre varios modelos de NVIDIA — gana la primera respuesta buena — y a los 15 s el cliente recibe una respuesta segura en vez de silencio. Sin clave de Anthropic, cada bot sigue andando por el respaldo igual que antes.

Baileys · licensing · single-PC deploy

Built for how small businesses actually runHecho para cómo funcionan de verdad los negocios chicos

The number they already haveEl número que ya tienen

Bots link the business's existing WhatsApp by QR or pairing code through the WhatsApp Web protocol (Baileys), with exponential-backoff reconnection and expired-session detection — no Business API onboarding or per-conversation fees.

Los bots vinculan el WhatsApp que el negocio ya tiene, por QR o código, con el protocolo de WhatsApp Web (Baileys), con reconexión con espera exponencial y detección de sesión vencida — sin trámite de la API Business ni costo por conversación.

Licences with a heartbeatLicencias con latido

Each club's Sedes instance checks in with Sonriar on a periodic heartbeat (version, WhatsApp status, last backup). If the account is suspended for non-payment, Sonriar answers so and the instance stops serving.

Cada instalación de Sedes le reporta a Sonriar con un latido periódico (versión, estado de WhatsApp, último respaldo). Si la cuenta se suspende por falta de pago, Sonriar lo responde y la instalación deja de atender.

Runs on the PC they ownCorre en la PC que ya tienen

The standalone bots use file-based storage — no database server — pick the next free port themselves and ask for a panel password on first launch. Voice notes via Whisper; receipts via OCR plus Claude.

Los bots independientes guardan en archivos — sin servidor de base de datos —, toman solos el próximo puerto libre y piden la clave del panel al primer arranque. Audios con Whisper; comprobantes con OCR más Claude.

More from the labMás del laboratorio

C# · DSP

EonTone

A multitrack looper played with the controller. All synthesis is hand-written: Karplus-Strong strings with Jaffe-Smith tuning (< 0.1 cent error), FM electric piano, PolyBLEP saws through a state-variable filter, modal marimba, a small Freeverb. It reads the controller over a local DSU/UDP feed from EonPS4Controller, so it never opens the device or fights its audio.

Un looper multipista que se toca con el joystick. Toda la síntesis está escrita a mano: cuerdas Karplus-Strong con afinación de Jaffe-Smith (error < 0,1 cent), piano eléctrico FM, sierras PolyBLEP por un filtro de variables de estado, marimba modal, una Freeverb chica. Lee el joystick por un canal DSU/UDP local de EonPS4Controller, así nunca abre el dispositivo ni se pelea con su audio.

LAYA

A Spanish voice assistant that controls Windows with no internet: voice detection → local Canary speech-to-text → a decision layer → actions. If it doesn't understand, it tries learned commands, then a local model, and only if enabled asks Claude — then offers to save what Claude solved as a new command, so it needs the cloud less over time.

Un asistente de voz en español que maneja Windows sin internet: detector de voz → Canary local de voz a texto → un decisor → acciones. Si no entiende, prueba los comandos aprendidos, después un modelo local y, solo si está activado, le pregunta a Claude — y ofrece guardar lo que Claude resolvió como comando nuevo, así cada vez necesita menos la nube.

Things find each otherLas cosas se encuentran solas

Each PC with EonCT broadcasts a small JSON over UDP every 3 seconds. A web page can't listen to UDP, so a native Android app was written just for that: open it on the same Wi-Fi and the PCs appear — no QR, no IP typing; one that goes silent for 15 s disappears.

Cada PC con EonCT anuncia un JSON chico por UDP cada 3 segundos. Una página web no puede escuchar UDP, así que se hizo una app nativa de Android solo para eso: la abrís en el mismo Wi-Fi y aparecen las PCs — sin QR, sin escribir IPs; la que se calla 15 s desaparece.

No build tool when none is neededSin herramientas de más

The Android app is built without Gradle on purpose: aapt2 → javac → d8 → zipalign → apksigner, in a short script. No outside libraries, hundreds of MB less to download, seconds instead of minutes. Same spirit everywhere: COM interop instead of NuGet packages, fetch instead of an SDK.

La app de Android se compila sin Gradle a propósito: aapt2 → javac → d8 → zipalign → apksigner, en un script corto. Sin librerías de afuera, cientos de MB menos para bajar, segundos en vez de minutos. El mismo criterio en todo: interop COM en vez de paquetes NuGet, fetch en vez de un SDK.

Solutions travelLas soluciones viajan

The "hold still to drag" gesture went from EonCT's touchpad to the PS4 controller's. EonPS4Controller's local UDP feed became EonTone's input. The Claude-first fallback became one module shared by four bots. A fix for one problem becomes a part for the next project.

El gesto de "quedarse quieto para arrastrar" pasó del touchpad de EonCT al del joystick de PS4. El canal UDP local de EonPS4Controller pasó a ser la entrada de EonTone. El "Claude primero" quedó como un módulo que comparten cuatro bots. Lo que arregla un problema se vuelve una pieza del próximo proyecto.

A3 · Architecture

How a message flows through Eon.

A Node/TypeScript backend keeps several WhatsApp sessions alive through Baileys, persists with Prisma (SQLite in dev, PostgreSQL in prod), encrypts stored WhatsApp credentials with AES-256-GCM and pushes live updates to the React panel over Socket.io.
